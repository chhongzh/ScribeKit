## 要点

**点题**：在文章的关键位置明确点出题目或主旨的字眼，让读者（阅卷人）看出文章围着什么写。教学资料称它是考场作文避免偏题最有效的手段，即使内容略偏，点得好也有扶正的效果。**扣题**则是通篇始终不离题目范围。点得好相得益彰，点得不好弄巧成拙，不能想点就点。

**位置与做法**
| 位置 | 作用 | 做法 |
|---|---|---|
| 标题 | 让人一眼看到主题 | 题目里嵌入主题字眼，紧扣主旨 |
| 开头 | 开门见山、尽快入题；引出下文；有悬念感；表明感情倾向 | 用精炼词语点示全文主要内容。例：《背影》开头“我最不能忘记的是他的背影” |
| 中间（过渡段、分论点、事例之后） | 小结前文、启示下文，最好同时点出主旨 | 一个部分之后点；点题句单独成段；分论点首句带题眼；议论文摆完论据后紧扣主题做分析 |
| 结尾 | 结束全文；最灵活、最容易出新 | 抒情、表愿望、提警示、描写诠释、直接点题、设问反问；与开头同一字眼形成首尾呼应 |

**结尾点题的四种常见方式**（教学文章归纳）：议论警示式；抒发感情、表达愿望式；描写诠释式；直接点示文题式。

**多处点题的具体办法**
- 原词重现：把题眼原样写出来。
- 近义替换、比喻替换：换成意思相同的词或形象。
- 内涵诠释：用一两句话解释题眼在本文里的意思。
- 每个主体段的段首和段尾回到题眼。
- 照应方式分三类：首段扣题、尾段照应；卒章显志、篇末扣题（起笔不顾题，到结尾才揭示含义）；语意扣题、隐形照应（意思相同、措辞不同，含蓄）。
- 标题含义一目了然的，行文可以反复点题（如每讲完一个故事就写一段与标题呼应的话）；标题含蓄的，在合适的地方点题（如《小桔灯》在多处出现“小桔灯”的物象）。

**要避免的毛病**
- 机械地“开头立意、中间点题点题点题、结尾升华”。有网友在评论中把这种节奏概括为套路作文的特征（见上列腾讯新闻文章转引）。点题次数多不等于扣题好；点题处如果没有新内容，只是重复口号，就是凑数。
- 点题句脱离上下文，单独看像是贴上去的。
- 点题字眼本身就是空泛的大词，却没有任何具体的人或事。

## 用于 Scaffolder

- 标题、梗概、主题字眼来自用户；先从用户的标题和梗概里提取题眼，再决定在哪些位置点。没有标题或梗概时按 `needs_user_input` 处理。
- 生成开头段：有题眼时，在前两句内出现题眼或其近义，并带一个具体的人、事或景，不用空泛的总述。
- 生成中间段（过渡段、分论点段）：默认在段首或段尾自然带一次题眼，用原词重现或近义替换交替，不连续三段使用同一句式。
- 生成结尾段：与开头的字眼或物象呼应，但换角度，不原样抄开头的句子；不喊口号、不加“让我们……吧”式训话。
- 点题要有内容依托。点题句紧跟或紧接具体描写、事例，不单独成为空话。
- 转折段、Call Back 段由用户亲自写。遇到这两类段落且未 `force`，只给 `advise`：说明这里适合点题的位置和可用的题眼，不给成文。
- 题眼出现频率：全篇每个主体段最多一次；一段内不重复两次以上。
- 隐形照应时，只改措辞不改意思，且要和用户已写的前文措辞保持一致，不引入新概念。

## 用于 Analyzer

- 文章级：`themeWords` 取自标题与梗概里反复出现的核心词；`themeHits` 为正文里题眼原词、近义词、比喻替换处。
- 段级 `marks`：
  - `theme`：题眼原词重现处。
  - `keyword`：题眼的近义或诠释语。
  - `callback`：与标题或开头呼应的结尾处。
  - `repetition`：同一词在相邻句里重复出现。
- 位置判断：
  - 标题含题眼；开头段前两句出现题眼；每个主体段段首或段尾出现题眼；结尾段出现题眼或与开头同一物象。
  - 开头与结尾共享同一字眼，视作首尾呼应。
- `paragraphs[].role` 可写：“开头点题”“中间点题（分论点）”“结尾点题”“无点题”。
- diagnostics（只陈述事实）：
  - “全文未出现标题中的字眼（X）”。
  - “第 n 段至第 m 段连续未出现题眼”。
  - “结尾未与开头呼应（开头出现 X，结尾未出现）”。
  - “第 n 段点题句与前文没有具体内容相连”。
  - “题眼在同一段内出现 3 次以上，间隔很短”。
- 不得判断“点题好不好”，只列位置、次数、是否缺位。
