## 要点

说明文以“说明”为主要表达方式，介绍事物的形状、构造、类别、关系、功能，解释事理的原理、含义、特点、演变。重在让读者“知”，议论文则重在让读者“信”。客观性强，语言要准确、严密、简明，在不损害准确的前提下可以生动。

**说明方法与作用**
| 方法 | 做法 | 通常的作用 |
|---|---|---|
| 举例子 | 用有代表性的事例说明事物或事理 | 具体化，便于理解，增强可信度 |
| 分类别 | 按性质、成因、用途等异同分类，逐类说明 | 条理清楚，层次分明 |
| 列数字 | 用具体数字说明 | 准确、科学、有说服力 |
| 作比较 | 把两类事物或现象放在一起比 | 突出被说明对象的特征 |
| 下定义 | 用简明科学的语言揭示本质属性 | 准确、概括 |
| 打比方 | 借两种事物的相似处作比，使抽象具体 | 生动形象，增强趣味 |
| 作诠释 | 对事物特征作具体解释，用通俗的话讲 | 通俗易懂 |
| 摹状貌 | 摹写形状、体貌 | 生动、逼真 |
| 引资料 | 引名言、典故、文献、新闻等 | 充实、增强权威性 |
| 画图表 | 用图画、表格 | 直观、清晰 |

**易混点**
- 下定义与作诠释：下定义揭示本质属性，句式固定（“X 是……”），前后项可互换；作诠释语言灵活，前后项不可互换。
- 打比方与比喻：打比方是说明方法，目的是让说明更形象；比喻是修辞手法，二者形式相似，要看所处的文体和目的。
- 举例子与打比方：“比如”“譬如”引出的是举例子；“如”有时同“像”，那是打比方。

**常见结构**：总分式、并列式、递进式、对照式（先总后分，或先分后总，或总分总；并列介绍不同方面；由浅入深；两事物对比说明）。

**写作步骤**：先明确说明对象和它的核心特征，再按特征选方法（功能多用分类别，智能化用举例子，规模用列数字，抽象的用打比方），然后用数字或比较把说明落实，最后检查语言是否准确、有无含糊词。

## 用于 Scaffolder

- 说明对象、要点和资料由用户给出。用户没有提供事实时，不补数字、年代、名称；在 `rationale` 里说明“这里需要具体数据，请补”。
- 数字必须来自用户素材或用户正文；没有就写成不带数字的描述，并提示用户。绝不虚构统计数据、来源、研究结论。
- 补写某条说明时，先明确用哪一种说明方法，一个说明点配一种主要方法。
- 语言：准确、简明、有条理；不用“大概”“可能”“很多”这类含糊词，除非是在表示推测。必须推测的地方明确写出是推测。
- 说明顺序要有逻辑（空间、时间、由主到次、由现象到本质），沿用用户已选的顺序，不随意打乱。
- 打比方只在原理抽象、读者难懂时用，比喻要贴切，并说明二者相同在哪里。
- 不加议论、不加抒情和口号；说明文里不写“让我们共同……”。
- 下定义要用“X 是……”句式，揭示本质属性；不用 X 本身去解释 X。
- 对比时要有共同的比较标准。

## 用于 Analyzer

- 说明文的半句多标 `narration`，`note` 写“说明”。判断句和解释性句子也属说明，不标 `argument`，除非出现作者的立场和劝说。
- 说明方法写入 `marks`（用 `note` 标方法名）：
  - 举例子：“例如”“比如”“譬如”引出具体事例，标 `evidence`。
  - 列数字：含具体数字与单位的半句，标 `evidence`。
  - 作比较：“比”“与……相比”“相对于”“而……则”，标 `rhetoric` 里的 `contrast`，note 写“作比较”。
  - 打比方：“像”“如同”“仿佛”，且有说明性意图，标 `simile` 或 `metaphor`，note 写“打比方”。
  - 下定义：“……是……的……”“所谓……就是……”，标 `keyword` 于被定义项，note 写“下定义”。
  - 作诠释：“也就是说”“即”“换句话说”，关系标 `explanation`。
  - 分类别：“分为”“可分为”“一类……另一类……”，关系标 `parallel`，note 写“分类”。
  - 引资料：引号加出处、“据……介绍”“研究表明”，标 `quotation`。
- diagnostics（只陈述事实）：
  - “断言性很强的句子后面没有数字、事例或出处”。
  - “出现含糊量词（很多、大量、许多、大概、可能）”。
  - “出现主观评价词或抒情句，与说明文体不符”，用 `hint`。
  - “同一说明点连续使用同一种方法超过三处”。
  - “说明顺序在同一段内混用多种标准”。
- 文章级 `structure`：判断总分、并列、递进或对照，列出缺失（如“缺总述”“缺结尾概括”）。
