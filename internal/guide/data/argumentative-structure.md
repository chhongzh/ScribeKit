## 要点

**三要素**：论点（作者对所议问题的见解和主张）、论据（用来证明论点的材料）、论证（用论据证明论点的过程，揭示论点与论据之间的内在逻辑）。

**论点**
- 论点应当是一个表态明确的完整判断句，而不是一个话题词。“梅花香自苦寒来”是题目，“苦难能磨出坚强的意志”才是论点。
- 一篇文章只立一个中心论点。同一材料可以读出几种启示，但只能选一个写透，几个并堆，结果是一个也说不清。
- 展开议论的关键是把中心论点分解成两三个分论点。

**论据的两类**
- 事实论据：具体的人、事、数据。有代表性、确凿、可核对才有力。
- 道理论据：公认的定理、规律，经典著作里的论断，名人名言。作用是增强权威性。

**常见论证方法与作用**（教学资料的通行说法）
| 方法 | 做法 | 通常的作用 |
|---|---|---|
| 举例论证 | 列举确凿、典型的事例 | 具体有力，增强说服力 |
| 引用（道理）论证 | 引经典论断、名言、公认原理 | 增强权威性 |
| 对比论证 | 正反两面或两种事物对照 | 突出观点，印象深 |
| 比喻论证 | 用熟悉的事物打比方讲道理 | 抽象道理变浅显生动 |
| 归纳论证 | 由若干具体事例推出一般结论 | 又称事实论证 |
| 演绎论证 | 由一般原理推到个别情形 | 又称理论论证 |
| 类比论证 | 从已知事物推到同类事物 | 特殊到特殊 |
| 因果论证 | 分析原因与结果的联系，可以因证果、果证因 | 揭示内在联系 |

驳论还会用“以子之矛，攻子之盾”和归谬法。

**论证结构**（四种，常嵌套使用）
- 总分式：提出问题（引论）、分析问题（本论）、解决问题（结论）。三段论是最常见的骨架，并列、层进、对照多出现在“本论”里。
- 并列式：把中心论点拆成几个平行的分论点，彼此地位相当。例：“梅花香自苦寒来”可拆为苦能激发进取心、能培养意志、能培养创造精神。
- 层进式：分论点由浅入深，顺序不可颠倒，后一层比前一层更深。例：先承认困难，再不怕困难，再研究并战胜困难；或由个人而社会而人类。
- 对照式：正反两面对照，常作为总分式里某一部分的写法。

**段内的论证写法**：一个分论点段最稳的写法是“观点句、阐释句、材料句、分析句、结论句”五步。最容易犯的错是只堆事例和名言，不写自己的分析。

## 用于 Scaffolder

- 论点、分论点、立意由用户写。用户没有给出论点时，不替用户发明论点，只给 `advise`，说明可以从哪几个角度拆。
- 用户已给出分论点后，补论证段时按顺序写：观点句（沿用用户的分论点，不改意思）、阐释句（说明为什么）、材料句、分析句、结论句。材料句之后必须有分析句，把材料与观点接上，不能让事例单独站着。
- 事实论据只用用户素材库或用户正文里已有的人和事。需要补事例时，先用 `search_materials`，查不到就在 rationale 里说明“这里缺事实论据，请用户补”，不要凭空编造人名、年份、数据。
- 不编造名言，不把一句话安到名人头上。引用必须有真实来源；没有把握的引文宁可不用，改写成转述并标明是概括。
- 同一篇里论证方法要换着用，不要每段都是“举例子加一句总结”。一个段落里最多叠两种方法。
- 并列式的分论点句式尽量整齐；层进式的分论点要写出递进的理由，不能只是把三个并列点换个顺序。
- 对比论证里正反双方都要有实质内容，并且要落到“所以正面观点对”，不要只摆两边就停。
- 比喻论证的喻体必须是读者熟悉的事物，不用生僻物象。

## 用于 Analyzer

- `claim`：表态明确的判断句，常含“是”“应当”“必须”“才能”“不是……而是……”，常出现在段首或段末，往往是分论点句。段首短句单独成段的多半是中心论点。
- `evidence`：含具体人名、事件、年份、数字的叙述；或带引号、出处、“正如……所说”的引文。前者是事实论据，后者是道理论据，写入 note。
- `reasoning`：分析性语句，常以“这说明”“可见”“正因为”“由此”“因此”“之所以……是因为”开头，把材料指回论点。
- 关系：材料句到论点句常是 `explanation` 或 `cause`；结论句常是 `summary`；正反对照是 `contrast`；分论点之间是 `parallel` 或 `progression`。
- 引文标 `quotation`，对照论证标 `contrast`，打比方论证标 `metaphor` 或 `simile`。
- diagnostics 可报的事实性问题：
  - 一段里有 `evidence` 但紧随其后没有 `reasoning`（“事例后没有分析”）。
  - 出现两个以上互不相干的中心论点。
  - 引文没有任何出处线索。
  - 分论点段的论据与分论点无关（对不上同一关键词）。
  - 连续多段都是同一套“举例、总结”的写法。
- 文章级 `structure`：判断属于总分、并列、层进还是对照，列出缺的环节，如“缺结论段”“分论点之间没有递进关系的标志”。不打分。
