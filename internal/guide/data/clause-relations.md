## 要点

复句里分句之间的逻辑关系由关联词语和意义共同决定。教学中常分为联合复句（并列、承接、递进、选择、解说）和偏正复句（因果、条件、假设、转折、让步、目的）。ScribeKit 的 `RelationKind` 取其中最常用的十二种。关联词是重要线索，但很多关系靠语序和意义表达，不带关联词。

| RelationKind | 含义 | 常见关联词 | 例 |
|---|---|---|---|
| `parallel` | 并列：几个分句平行，没有主次 | 既……又……、也、又、同时、一面……一面……、不是……而是……、有的……有的…… | 绿既是美的标志，又是富足的标志 |
| `sequence` | 承接：动作或事件按先后相继 | 就、便、才、于是、然后、接着、首先……然后……、一……就…… | 他先把行李堆好，又去和脚夫讲价 |
| `progression` | 递进：后一分句比前一分句进一层 | 不但（不仅、不光）……而且（并且、还、也）……、甚至、何况、尚且……何况……、别说……就是…… | 他不仅学习好，而且工作好 |
| `contrast` | 转折：后文转向相反的意思 | 但（是）、可是、然而、却、不过、虽然（尽管）……但是…… | 天气虽然冷，我身上还在出汗 |
| `concession` | 让步：先承认一种情况，然后说不受它影响 | 即使（即便、就算、哪怕、纵然、纵使）……也（还）……、再……也…… | 即使他不来，我们也要这样做 |
| `cause` / `result` | 因果：原因与结果 | 因为（由于）……所以（因此、因而）……、既然……就（那么）……、之所以……是因为…… | 因为他有信心，所以不怕失败 |
| `condition` | 条件（含假设）：某条件下出现某结果 | 只要……就……、只有（除非）……才（否则）……、无论（不论、不管）……都……；假设：如果（假如、倘若、要是）……就（那么）…… | 只要专心，就能做成 |
| `purpose` | 目的：为达到或避免某结果而行动 | 为（为了）、以、以便、以期、好、为的是；避免：以免、免得、省得 | 请保管好现金，以免被偷走 |
| `explanation` | 解说：后一分句解释前一分句 | 多无关联词，靠冒号、破折号、“即”“就是”“也就是说” | 他有两样爱好：钓鱼和下棋 |
| `supplement` | 补充：后一分句补一句说明 | 多无关联词，括注式、“另外”“此外”“顺便说” | 车夫扶起了她（那时路上几乎没有人） |
| `summary` | 总分：先总说后分说，或先分说后总括 | 先总后分：冒号、数量词、“有的……有的……”；先分后总：“都”“总之”“这一切” | 春天有三件事：花开了，草绿了，风暖了 |

### 方向约定
本指引采用：`from` 是语序上靠前的半句，`to` 是靠后的半句，`kind` 描述 `to` 相对 `from` 的关系。因为 A，所以 B：from=A，to=B，kind=`result`。B，因为 A（倒装）：from=B，to=A，kind=`cause`。其余同理。
（SPEC 对方向没有作进一步约定；若实现采用相反约定，只需整体对调。）

### 易混点
- “不是……而是……”是并列；“不是……就是……”是选择（二选一），ScribeKit 把选择归入 `parallel`，note 写“选择”。
- “即使……也……”既可表假设又可表让步，看语境：说的是未发生的假设用 `condition`，说的是承认某事实仍然不受影响用 `concession`。
- “尚且……何况……”是递进；“虽然……但是……”是转折；“既然……就……”是由已知前提推出结论，归因果。
- “于是”常是承接，也可带因果意味，看前文是否交代原因。
- 目的复句里“为了”可放在行为前或行为后，意思不变。目的是想达到的，用“以、以便、为的是”；想避免的，用“以免、免得”。
- 不带关联词的句子关系靠语序和意义：动作先后给 `sequence`，前一句铺垫后一句解释给 `explanation`，上一句说结论下一句说理由给 `cause`。

### 在文章中的作用
- 转折和递进的重心都落在后一分句上：“虽然……但是……”“不但……而且……”，表达的用意在后者。
- 转折和让步是文章的“转弯”处，用在转折段和辩证处。
- 递进让论证一层比一层深；并列让几个角度并排站住。
- 关联词不是越多越好。连词密、关系线整齐，是机器写作的常见特征；人写的东西常把关系藏在语序和细节里。

## 用于 Scaffolder

- 先判断用户已写的上一半句与要续写的半句应是什么关系：续写光标处时，沿用已写部分显露出的关系，不要随意改成转折或因果。
- 关联词按真实逻辑选用，不为“显得有逻辑”而加。叙述里的承接尽量用动作先后自己带出来，少用“然后”“接着”“于是”连缀。
- 让步与转折（`concession`、`contrast`）会改变文章走向：在转折段和 Call Back 段里由用户来写；其他段落里需要时给 `advise`，说明可在哪个位置转折。
- 一个段落里关联词最多两三处，避免“首先、其次、再次、最后”“不仅……而且……”“因此、所以、综上所述”连续出现。
- 并列项要真的并列，同一层级；递进项要真的有递进，后一项不是前一项的同义改写。
- 因果要有依据：写出“因为……所以……”时，原因在用户已写事实里能找到；找不到就不要硬造原因。
- 目的复句：想达到的用“为了、以便”，想避免的用“以免、免得”，不混用。
- 补写句子时避免把前后半句都挂满关联词（“虽然……但是……，因为……所以……”叠用）。

## 用于 Analyzer

- 每组相邻半句判断关系，写 `relations`：`from`、`to` 为半句 index（遵守上面的方向约定），`kind` 取十二种之一，`note` 写触发的关联词或依据（如“因为……所以”“语序承接”“冒号解说”）。
- 先找显式关联词，再看语序与标点：
  - 冒号、破折号后接内容：`explanation` 或 `summary`。
  - “有的……有的……”“一是……二是……”：`parallel`；若前有总括句则同时有 `summary`。
  - 时间副词和动作链：`sequence`。
- 同一对半句可以有多个关系时优先标最显著的一个，在 note 里写明另一个。
- 跨句关系也标（用半句 index 指到相邻句的首尾半句），但不跨越三个以上半句，以免臆测。
- 关联词配对残缺（“虽然”无“但”、“因为”无“所以”）不算错，因为汉语常省略；只有明显歧义时在 diagnostics 提示 `hint`。
- diagnostics 可报的事实：
  - 同一关联词在同一段内出现三次以上（如“然后”“接着”“因此”）。
  - 相邻半句之间没有任何可识别的关系线索（无关联词、无承接、无指代），可提示“与前文衔接不明”，severity 用 `hint`。
  - 一个段落里关系几乎全是同一种（全是 `sequence` 或全是 `parallel`）。
- 文章级 `notes`：列出转折点（`contrast`/`concession` 集中处）在哪几段，供用户检查结构，不评价。
